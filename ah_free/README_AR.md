# تطبيق شيلات عبدالهادي الحبابي — النسخة المجانية

هذه النسخة لا تستخدم Firebase Storage، لذلك لا تحتاج إلى ترقية Firebase إلى Blaze من أجل تخزين ملفات الشيلات داخل Firebase.

## ما الذي يعمل؟
- تسجيل دخول الأدمن عبر Firebase Authentication.
- التحقق من صلاحية الأدمن من Firestore عبر `admins/{UID}` و `role = admin`.
- إضافة وتعديل ونشر وإخفاء وحذف الشيلات.
- حفظ بيانات الشيلة في Firestore.
- تشغيل MP3 من رابط مباشر.
- عرض صورة الغلاف من رابط مباشر.
- عداد تشغيلات.

## مهم: ملفات MP3 والصور
في صفحة «إضافة شيلة» لا يوجد رفع مباشر للملفات إلى Firebase. بدل ذلك تضع:
- رابط MP3 مباشر يعمل عبر HTTPS.
- رابط صورة مباشر عبر HTTPS (اختياري).

يمكنك استخدام أي خدمة تخزين مجانية مناسبة توفر روابط مباشرة للملفات. لا تضع روابط صفحات مشاركة عادية إذا لم تكن تعيد الملف نفسه؛ التطبيق يحتاج رابط الملف المباشر.

## Firebase
1. أنشئ Cloud Firestore بالوضع الإنتاجي.
2. فعّل Authentication > Email/Password.
3. أنشئ مستخدم الأدمن في Authentication.
4. في Firestore أنشئ `admins/{UID}` مع:
   - `role` = `admin`
   - `name` = `عبدالهادي الحبابي`
5. ضع `google-services.json` داخل `android/app/`.

## قواعد Firestore
استخدم القواعد الموجودة في `firestore.rules`.

## التشغيل
```bash
flutter pub get
flutter run
```

> ملاحظة: هذه النسخة تتجنب Firebase Storage فقط لتجنب الحاجة إلى Blaze. إذا أردت رفع الملفات مباشرة من داخل التطبيق لاحقًا، يمكن إضافة خدمة تخزين خارجية تدعم الرفع المجاني أو العودة إلى Firebase Storage مع Blaze.
